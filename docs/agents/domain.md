# Domain docs

Before exploring, read:

- `tcc/glossario.md` — project vocabulary. Use its terms in issues, specs, tests and names.
- `tcc/decisoes.md` — numbered project decisions. If your output contradicts one, say so explicitly ("contradicts decisão 1, because…") instead of overriding it silently.

If a concept you need is missing from the glossary, either you are inventing language (reconsider) or there is a real gap (add it).
