# 07: Montar protótipo demonstrativo

**What to build:** Demonstrar a biblioteca open source de rotulagem assistida de dados financeiros em um caso de crédito: preparar exemplos, configurar e executar fine-tuning/inferência local de modelo leve (se aprovado), revisar sugestões humanas e rastrear resultados. Demonstrar reconfiguração sem reescrever etapas comuns e portabilidade para uma segunda base aprovada. Não alegar suporte universal nem compliance automático.

**Blocked by:** 06 — Executar avaliação final e análise de sensibilidade.

**Status:** ready-for-agent

- [ ] Definir um fluxo simples de preparação de exemplos, sugestão de rótulos, revisão humana e auditoria.
- [ ] Comparar rótulos sugeridos contra referências e baseline apropriado.
- [ ] Conferir saídas do protótipo contra execuções reproduzíveis da biblioteca.
- [ ] Registrar exemplos e capturas úteis para a monografia e apresentação.
- [ ] Registrar modelo, dados de treino, configurações, versões e decisões humanas.
- [ ] Definir com o orientador se SCR.data continua relevante para o novo recorte; caso contrário, mantê-lo fora do protótipo inicial.
- [ ] Mostrar claramente que o caso de crédito é uma demonstração do fluxo configurável; não alegar suporte universal para qualquer base ou problema.
- [ ] Decidir se uma interface faz parte do TCC ou se a biblioteca CLI/API e documentação bastam para demonstrar o fluxo.
